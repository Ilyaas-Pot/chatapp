## What This App Does

ChatApp is a Java console application where users can register, log in, and send messages. It validates credentials, generates message IDs, creates message hashes, and stores messages in a JSON file.

## How to Run

1. Clone the repository
2. Open the project in NetBeans
3. Right-click the project and select Clean and Build
4. Right-click the project and select Run

## How to Run Tests

Right-click the project and select Test
Or run: mvn test
